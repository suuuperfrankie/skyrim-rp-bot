Skyrim RP Bot - Setup

1 / 5

Welcome

This is a one-time setup, takes ~3 minutes. You'll need:

  • A Twitch account (the channel where the bot will run)
  • Internet access
  • OBS Studio installed

No coding required. The bot remembers everything once you finish, so you only do this once.

Step 1 - Register a Twitch app

Twitch needs to know about your bot. This is free and takes a minute.

  1. Open the Twitch Developer Console: Open dev.twitch.tv ↗
  2. Click Register Your Application.
  3. Fill in the form:
    Name anything (e.g. "My RP Bot")
    OAuth Redirect URLs http://localhost
    Category Chat Bot
    Client Type Public
  4. Click Create, then on the new app click Manage.
  5. Copy the Client ID from that page - you'll paste it in the next step.

Step 4 - Set up OBS

Add a Browser Source to the scene where you want the panel to appear.

  1. In OBS, in the Sources panel, click + → Browser.
  2. Name it Skyrim RP Panel, click OK.
  3. Set the properties:
    URL http://localhost:3000/overlay/
    Width 1920
    Height 1080
    Custom CSS (leave default)
    "Shutdown source when not visible" leave OFF
    "Refresh browser when scene becomes active" ON (recommended)
  4. Click OK. The browser source will be transparent until a round is active.

1920 × 1080 covers the full stream canvas. You can re-position and scale it within OBS as needed.
