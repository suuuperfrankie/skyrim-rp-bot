Roleplay Mode

Mixed = random finalists. Serious / Funny prioritize suggestions that fit the chosen vibe (still picks from real chat suggestions; just biases the selection).

A small label appears in the OBS suggestion panel showing the active mode (hidden in Mixed).

Round Settings

Changes save instantly. The bot's chat messages use these values, so updating a timer also updates the announcement (e.g., "you have 30s").

Stream Deck / Hotkey URLs

Use the Stream Deck "Website" or "System: Open" action with these URLs (no plugin needed). They take effect instantly. Mod/broadcaster auth is bypassed because they're called from your local machine.

Customize Overlay

Drag a slider or type a value. Changes apply live to the OBS overlay and persist between sessions.
